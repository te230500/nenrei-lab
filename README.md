# 年齢推定 Lab

年齢推定の確率モデル・適応型質問選択・標本バイアスを調べる非公式の個人研究プロジェクト。

元のゲーム: https://kepigame.com/games/nenrei.html

## 現在の実験版: v0.6

- 現行方式と複数の改良方式を比較
- 学習確率の反復補正、頑健推論、分野別の文化接触時期モデル
- 外部資料を使った質問追加と標本バイアスの感度分析
- ローカルで回答し、任意で実験ログを保存する設計

変更内容は [CHANGELOG.md](CHANGELOG.md) を参照。

## 公開範囲

この公開リポジトリは現時点では独自の研究記録のみを収録する。元ゲームのコード・質問・学習集計の再配布許諾は未確認のため、これらを含む実行版は収録していない。元作者とは無関係の非公式研究であり、第三者素材にライセンスを付与するものではない。

個人の回答ログは公開しない。実験で得た結果は一般化性能を保証しない。
